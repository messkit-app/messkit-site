# messkit.app

The public page for [Messkit](https://messkit.app), a kitchen inventory app in development by Messkit LLC.

Static HTML, no build step, no JavaScript, no cookies, no analytics. Served by GitHub Pages from `main`.

This repository is public because GitHub Pages is free only for public repositories; the app itself lives in the private `messkit-app/messkit` repository. **Nothing secret goes in here** — no keys, no tokens, no unpublished plans.

Editing: change the HTML, commit to `main`, and Pages redeploys. Design tokens are copied from `docs/design/tokens.md` in the app repo; keep them in step by hand.
